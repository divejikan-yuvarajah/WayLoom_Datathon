# WayLoom Datathon

Rootcode Tech-Triathlon 2026 Datathon project.

This repository contains the Datathon documentation and implementation workspace for Task 1, Task 2A, and Task 2B. The central planning document is `MD Files/WAYLOOM_DATATHON_MASTER_PLAN.md`.

## Phase 01 status

Phase 01 establishes the secure local environment, configuration, logging, and reproducibility controls. Phase 02 is the first phase permitted to inspect or inventory official competition files.

## Data safety

Official competition data and private derivatives are local-only restricted material. Follow `docs/repository_data_policy.md`. Never commit, publish, transmit, or expose competition rows or derivatives.

## Setup

Read `docs/reproducibility.md` for environment creation and verification instructions.
